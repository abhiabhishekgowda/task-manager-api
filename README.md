# 📝 Task Manager API

A backend Task Manager API built with **Python, FastAPI, and SQLite**.

## 🚀 Features

* Create a task
* View all tasks
* Search task by ID
* Update a task
* Delete a task
* Store data permanently using SQLite

## 🛠 Tech Stack

* Python
* FastAPI
* SQLite
* Uvicorn

## 📂 Project Structure

```text
main.py
database.py
tasks.db
```

## ▶️ Run the Project

1. Install dependencies
2. Run:

```bash
uvicorn main:app --reload
```

3. Open:

```
http://127.0.0.1:8000/docs
```
